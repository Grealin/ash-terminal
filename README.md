# ash-terminal

使用Electron + React + TypeScript + Tailwind + Jotai构建的智能远程终端。

主要功能：

- 多会话SSH连接管理
- 文件传输
- 系统监控
- 终端仿真
- 批量命令执行
- Ai助手集成

软件特点：

- 主题和布局自定义
- 支持Windows、macOS和Linux多平台运行

## Project Setup

### Install

```bash
$ yarn
```

### Development

```bash
$ yarn dev
```

### Build

```bash
# For windows
$ yarn build:win

# For macOS
$ yarn build:mac

# For Linux
$ yarn build:linux
```
